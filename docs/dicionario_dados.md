# Dicionário de Dados

- `clientes`: cadastro fictício de clientes.
- `produtos`: catálogo fictício com preços e custos.
- `pedidos`: cabeçalho dos pedidos, canal, status e desconto.
- `itens_pedido`: produtos e quantidades de cada pedido.
- `pagamentos`: forma, valor, vencimento e situação do pagamento.

Todos os dados são fictícios e destinados exclusivamente a estudo.
